Как проект построен

  • REST + Static UI: Spring Boot отдаёт API и две статические страницы без отдельного frontend build-step.
  • Persistence split: PostgreSQL держит транзакционные данные, Elasticsearch ускоряет поиск по советам.
  • Messaging: Kafka принимает training events и nutrition notifications для асинхронных сценариев.
  • Scalability add-ons: Redis и k6 уже встроены в историю проекта как кэш и нагрузочное тестирование.
